# Cozy Cart

Frontend Technology Stack

Framework: TanStack Start with React

Language: TypeScript

Routing: TanStack Router

Styling: Tailwind CSS

UI components: shadcn/ui

Icons: Lucide React

Animations: Motion for React (Framer Motion)

Forms: React Hook Form

Validation: Zod

Data fetching: TanStack Query with mock asynchronous services

Cart state: React Context + useReducer, persisted in localStorage

Code quality: ESLint and Prettier

Implement only the frontend in this phase. Use local mock data; do not add database connections, backend business logic, real authentication, or live payment processing. Keep components and data services ready for future Supabase and PayHere integration.
